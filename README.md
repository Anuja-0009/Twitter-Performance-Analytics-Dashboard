# Twitter Performance Analytics Dashboard

## Project Overview
This project analyzes Twitter performance data using Power BI. The dataset was cleaned and prepared using Microsoft Excel and visualized through interactive dashboards.

## Tools Used
- Excel (Data Cleaning)
- Power BI (Data Visualization)
- GitHub (Project Hosting)

## Dashboard Features
- Total Tweets KPI
- Average Impressions
- Engagement Rate
- Media Engagements
- Top 10 Tweets by URL Clicks
- Tweets by Weekday
- Media Views vs Media Engagement

## Insights
- Identify which tweets generate the most engagement
- Analyze tweet performance by weekday
- Compare media views with engagement levels
